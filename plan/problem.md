### The core capability checklist (website brief)

PDF A and B say: "All six topics share the same core capability requirements and scoring criteria". The PDFs never list those requirements. The website brief does, and it is the closest thing to a scoring script:

> "Select one direction and deliver a working financial Agent that demonstrates intent understanding, task planning, safe execution, user control and measurable value in a financial scenario." (WEB, Challenge Brief)

We treat the five capabilities as the judges' real checklist: **intent understanding · task planning · safe execution · user control · measurable value**.
